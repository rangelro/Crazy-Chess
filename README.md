# Crazy-Chess

Um projeto de xadrez com mecânicas diferenciadas (“crazy chess”).

## Sobre

Este repositório contém a base do projeto **Crazy-Chess**.

## Funcionalidades (planejadas)

- Tabuleiro e peças de xadrez
- Regras personalizadas
- Controle de turnos
- Interface para partidas locais

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/rangelro/Crazy-Chess.git
cd Crazy-Chess
```

2. Siga as instruções de execução conforme a stack do projeto.
